# NormTab
You can see origin code of NormTab from here : [https://github.com/mahadi-nahid/NormTab]

## 📌 Overview

This project evaluates **WikiTableQuestions (WTQ)** using **normalized tables (NormTab)** as input.
The pipeline generates SQL queries with LLMs (Qwen, GPT, etc.), executes them on a SQLite engine, and compares the predictions with the gold answers.

---

## 🚀 Usage

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Run evaluation

```bash
python normtab_wtq_eval.py
```

* Results will be automatically saved under `outputs/` and `logs/`.
* Normalized tables are loaded from `outputs_GPT4/normTab_targeted_wtq_gpt4.csv`.

---

## 📝 Output Files

1. **JSONL (`outputs/normTab_eval_targeted_wtq.jsonl`)**

   * Contains predictions per question in the format:

     ```json
     {"key": "nu-165", "question": "who was the first cyclist to finish?", "prediction": "alejandro valverde", "answer": "alejandro valverde"}
     ```

2. **CSV (`outputs/normTab_eval_targeted_wtq.csv`)**

   * Stores results in tabular form with fields:

     ```
     id, question, answer, prediction, sql, response
     ```

3. **Logs (`logs/nu-xxxx_log.txt`)**

   * Each file records:

     * The exact **prompt** given to the model
     * The **raw model response** (including `<think>` or `<table>` if present)

   * Example:

     ```
     ==== PROMPT ====
     <full prompt here>

     ==== RAW RESPONSE ====
     <model output here>
     ```

---

## ⚙️ Qwen-Specific Postprocessing

Qwen models often include special reasoning tokens like `<think>...</think>` or `<table>...</table>`.
A preprocessing step was added to **remove these tags** before extracting the final SQL.
This ensures clean execution on SQLite without syntax errors.
